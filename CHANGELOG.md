# Журнал изменений

## 1.1.0 — 2026-08-14

Первый публичный релиз.

### Основное

- единый прозрачный оверлей Twitch и YouTube для Windows 10/11;
- настройка платформ через русский интерфейс без обязательного `.env`;
- автоматический поиск текущей и следующей трансляции YouTube по ссылке на канал;
- проверка Twitch-токена и автоматическое определение его владельца;
- Windows DPAPI для локального хранения токена Twitch и ключа YouTube;
- режим редактирования и режим со скрытыми границами/click-through;
- глобальные горячие клавиши, автозапуск и работа через область уведомлений;
- звуки новых сообщений с выбором варианта и громкости;
- фильтры команд, пользователей и слов;
- актуальные иконки приложения, EXE, трея и платформ;
- компактные карточки с цветами Twitch-пользователей и мягким цветом YouTube-ников;
- корректный перенос длинного текста и удаление карточек, не помещающихся в окно;
- автоматические тесты основных моделей, клиентов, парсеров и конфигурации.
